Install kaise karein?

Ye app Play Store par nahi hai, isliye phone "Play Protect" ka warning dikha sakta hai. Ye normal hai, bas niche ke steps follow karein. Screen namune ke liye hain, aapke phone par thoda alag dikh sakte hain. Hare gol wale button par dabana hai.

1
Download hone ke baad agar "File harm kar sakti hai" likha aaye, to Download anyway / Keep dabayein. Phir Open dabayein.
2
Agar "Install unknown apps" ka message aaye, to Settings dabayein aur Allow from this source ON kar dein. Wapas aakar Install dabayein.
3
Play Protect ka box aaye ("Scan app" / "App blocked"), to Scan app ya OK par na dabayein. More details dabayein, phir Install without scanning ya Install anyway chunein.
4
Install hone ke baad Open dabayein. Ho gaya!
